# MuSync (Yandex Music Fork)

> Показывает текущий трек из музыкального плеера прямо в вашем статусе Steam — **Mu**sic **Sync**.
>
> Форк оригинального проекта [kernel12345/musync](https://github.com/kernel12345/musync) от **QaEDZ** с добавленной поддержкой **Яндекс Музыки** и полным переводом интерфейса на русский язык.

После входа в Steam друзья видят в вашем статусе «В игре» текущий трек, исполнителя и живую полосу прогресса:
`Группа крови - Кино [#####-----] 2:30/4:15`

## ✨ Что нового в этом форке (by QaEDZ)

- 🟡 **Поддержка Яндекс Музыки** — работает с официальным десктопным приложением (`Яндекс Музыка.exe`, Electron) и UWP-версией через Windows SMTC (без костылей, чтения памяти и дополнительных параметров запуска): трек, исполнитель, альбом, обложка и прогресс.
- 🇷🇺 **Полностью русский интерфейс** — главное окно, карточки плееров, настройки, фарм часов, рабочий стол, журнал работы, меню в трее и диалоги входа Steam.

## 🎵 Возможности

- **Поддержка нескольких плееров**: Яндекс Музыка / NetEase Music / QQ Music / Soda Music
  - Автоматический выбор активного плеера: приоритет у того, что сейчас играет; при паузе статус переключается на подпись в простое или активное приложение
  - Яндекс Музыка и Soda Music читаются через системную медиасессию Windows (SMTC)
- **Интерфейс Windows 11 Fluent**: WPF + [WPF-UI](https://github.com/lepoco/wpfui)
  - Фон Mica, автоматическая смена светлой и тёмной темы вслед за системой
  - Навигация: Главная / Плееры / Фарм часов / Рабочий стол / Журнал / Настройки / О программе
  - Карточки плееров на главной с обложкой, названием трека, исполнителем, альбомом и прогрессом
  - **Фарм часов** — чтение библиотеки Steam и запуск до 30 игр одновременно (включая выпадение коллекционных карточек) без прерывания синхронизации музыки
- **Прямое подключение к Steam**: на базе `SteamKit2`, клиент Steam может быть закрыт
  - Автопереподключение и автовход по токену
  - Автоматическая пауза синхронизации музыки, когда вы запускаете настоящую игру в Steam
- **Статус в простое**: своя подпись или показ текущего активного приложения, пока музыка не играет
- **Работа в трее**: автозапуск с Windows, сворачивание в трей при закрытии и при старте, управление паузой из контекстного меню
- **Рабочий стол**: плавное скрытие значков двойным кликом по пустому месту и регулировка прозрачности значков
- **Безопасность**: токены входа Steam шифруются через Windows DPAPI
- **Журнал**: встроенный просмотр логов и запись по дням в `%LocalAppData%\MuSync\logs\`

## 📥 Использование

1. Скачайте готовый `MuSync.exe` из раздела [Releases](https://github.com/QaEDz/musync-YandexMusic/releases) (или соберите проект самостоятельно)
2. При первом запуске войдите в аккаунт Steam (поддерживается Steam Guard по мобильному приложению и почте)
3. Запустите **Яндекс Музыку** (или любой другой поддерживаемый плеер) и включите трек — статус обновится автоматически

> Сессия `MuSync` в Steam работает параллельно с основным клиентом Steam и не выбивает его из сети (как ArchiSteamFarm).

## 🔨 Сборка и тесты

```powershell
dotnet build MuSync.sln -c Release     # Сборка
dotnet test MuSync.sln                  # Запуск модульных тестов (42 теста)
```

Публикация в один самодостаточный `.exe` (не требует установленного .NET):

```powershell
dotnet publish MuSync.csproj -c Release -r win-x64 --self-contained `
  -p:PublishSingleFile=true
```

Готовый файл появится по пути: `bin/Release/net9.0-windows10.0.19041.0/win-x64/publish/MuSync.exe`.

## 🗂️ Структура проекта

```
App.xaml / MainWindow.xaml     # Точка входа WPF и главное окно (Mica + NavigationView)
Views/Pages/                   # Страницы: Главная / Плееры / Фарм часов / Рабочий стол / Журнал / Настройки / О программе
Themes/SettingsCardStyle.xaml  # Стили карточек в стиле Windows 11
Services/                      # AppServices / TrayIconService / DesktopIconService / MemoryOptimizer
RpcManager.cs                  # Опрос плееров и выбор активного источника
SteamStatusManager.cs          # Форматирование и отправка статуса в Steam
SteamSessionManager.cs         # Сессия SteamKit2, DPAPI-токены, отправка games_played
SteamLibraryResolver.cs        # Чтение библиотеки игр через LicenseList + PICS
Players/                       # Яндекс Музыка и Soda Music (SMTC), NetEase и QQ Music (чтение памяти)
Utils/ImageCacheManager.cs     # Кэш обложек (фоновая загрузка и декодирование)
tests/MuSync.Tests/            # Модульные тесты (xUnit)
```
